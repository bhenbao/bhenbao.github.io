# Chenhao Sun — Portfolio

This repository contains the source for [bhenbao.github.io](https://bhenbao.github.io), a personal portfolio built with Jekyll and hosted on GitHub Pages.

## Customize

- Edit the introduction and project cards in `index.html`.
- Update colors, typography, and responsive styles in `assets/css/style.css`.
- Add future projects to the **Selected work** section as they are ready to share.
